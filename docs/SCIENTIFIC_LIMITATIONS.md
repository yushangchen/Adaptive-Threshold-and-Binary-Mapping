# Scientific limitations

1. AT-BM detects pressure states, not instantaneous separation lines.
2. One-bubble-like and two-bubble-like are pressure-based descriptors.
3. Decimal pattern identifiers have no ordinal physical meaning.
4. Near-zero SAI does not prove instantaneous bilateral symmetry.
5. Lower-region activity may include ground-boundary-layer and horseshoe-vortex
   influences.
6. Automatic clustering is an initialization and requires scientific review.
7. Representative Fig. 8 thresholds must not be applied universally to all taps.
8. Cross-Reynolds-number comparison requires fixed post-selection thresholds.
